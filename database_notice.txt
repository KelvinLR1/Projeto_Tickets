# INFORMAÇÕES IMPORTANTES SOBRE O BANCO DE DATOS

O TicketFlow suporta dois tipos de banco de dados:

1. SQLITE (Padrão):
   - Não requer NENHUMA instalação adicional.
   - O sistema funcionará imediatamente após a instalação.
   - Ideal para uso local ou pequenas equipes.

2. POSTGRESQL (Recomendado para Produção):
   - Requer que o PostgreSQL esteja instalado no servidor.
   - Se você deseja usar PostgreSQL, baixe e instale-o antes de prosseguir:
   - Link para Download: https://www.postgresql.org/download/windows/

TEMPO ESTIMADO DE INSTALAÇÃO:
- A instalação completa pode levar de 3 a 5 minutos, dependendo da velocidade do seu disco, devido à extração dos módulos do ambiente Python e Node.js.
